# ازرع الآن

تطبيق عربي خفيف يعرض اقتراحات محاصيل إرشادية للزراعة داخل السودان حسب شهر
الزراعة ونوع التربة. يقتصر البحث عن المدن وتحديد الموقع على السودان، ويمكن عرض
الطقس الحالي عبر Open-Meteo للمواقع السودانية.

## التشغيل عبر Jekyll

شغّل الموقع محليًا من مجلد المشروع:

```sh
jekyll serve --host 0.0.0.0 --port 3000
```

ثم افتح <http://localhost:3000>. لبناء نسخة النشر داخل مجلد `_site`:

```sh
jekyll build
```

إعدادات الموقع في `_config.yml`، وتُعالج الصفحة الرئيسية عبر Jekyll.

البحث عن المدن والطقس يحتاجان اتصالًا بالإنترنت. تحديد الموقع الجغرافي يعمل على
localhost أو عبر HTTPS بعد موافقة المستخدم.

## ملاحظات عن البيانات

- تقويم المحاصيل المضمّن عام وليس تقويمًا محليًا معتمدًا للسودان.
- تختلف مواعيد الزراعة داخل السودان حسب المنطقة والارتفاع والصنف والطقس المحلي؛
  تحقّق من الإرشاد الزراعي في منطقتك قبل الزراعة.
- نوع التربة اختيار يدوي؛ OpenStreetMap لا يوفر تحليلًا زراعيًا للتربة.
- يُعرض الطقس الحالي للسياق فقط، ولا يُستخدم للتنبؤ بنجاح المحصول.
- يمكنك إضافة المحاصيل وتعديلها وحذفها؛ تُحفظ بياناتك محليًا في المتصفح نفسه ولا يوجد حدّ لعدد السجلات داخل التطبيق. تظل السعة الفعلية خاضعة لحدود المتصفح والجهاز، ومسح بيانات الموقع قد يحذفها.
- تُنسب بيانات الخرائط إلى مساهمي OpenStreetMap. خدمة الطقس من Open-Meteo.
